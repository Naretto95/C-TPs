# TP2 — Introduction to C

A set of short, standalone programs covering the very basics of C: input/output,
variables, conditionals, loops and arrays.

| File | Description |
| --- | --- |
| [tp2q1.c](src/tp2q1.c) | Reads an integer and prints it back. |
| [tp2q3.c](src/tp2q3.c) | Reads two integers and prints them back. |
| [tp2q4.c](src/tp2q4.c) | Reads a name, first name and date of birth, then prints them back. |
| [tp2q5.c](src/tp2q5.c) | Divides two integers, guarding against division by zero. |
| [tp2q6.c](src/tp2q6.c) | Computes the calendar date of the day after a given date, including leap years. |
| [tp2q7.c](src/tp2q7.c) | Maps a Richter scale value (1-9) to its description. |
| [tp2q8.c](src/tp2q8.c) | Computes how many years it takes for compound interest to reach a target amount. |
| [tp2q9.c](src/tp2q9.c) | Reads a list of integers and finds its minimum and maximum. |

## Build & run

```sh
make            # builds every exercise into bin/
./bin/tp2q1     # run a specific exercise
make clean
```
